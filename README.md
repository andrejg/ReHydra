# ReHydra
An adaptation of the Hydra network card for Atari ST/TT/Falcon series of computers, making it work with obtainable modern RJ45 jacks like Hanrun HR911105A.

The original design (https://www.atariworld.org/hardware/hydra/) was done by Mathias Münch in 2009 and published under Attribution-NonCommercial-ShareAlike 4.0.
